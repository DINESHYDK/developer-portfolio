# Dinesh Krishna — Portfolio

Personal site: projects, competitive programming stats (live from LeetCode, Codeforces and CodeChef), and a contact form.

Live: https://portfolio.dineshydk.tech

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` with:

```
VITE_CODECHEF_API_URL=...
VITE_WEB3FORMS_KEY=...
```

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion. Deployed on Vercel.
